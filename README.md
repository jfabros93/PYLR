# PYLR

A multi-tenant Church Management System (CHMS) — service/gathering scheduling, an internal event planner with resource-booking approvals, and a congregant-facing app for public events, ticketing, and giving.

This repository is at the design stage. See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the recommended tech stack, system architecture, full data model, key workflows, and the phased implementation roadmap.
